# WS6 — M2: маленький город (день)

**Уровень плана:** милестоун. Детализировать задачи (RED/GREEN) **после** WS5 — сейчас зафиксированы рамки,
контракты и порядок, чтобы следующая модель не расползлась по объёму.

**Решение владельца (GDD §36.1, 2026-09-26):** город маленький и уютный. Одна улица, депо, **≤4 интерьера** на
релизе (лавка, пансион, контора компании, дом доктора), водонапорная башня / ворота шахты — только фасады.
Лучше меньше мест на уровне §35, чем много на уровне прототипа.

**Зависит от:** WS5 (ночи из данных, сохранение между ночами).

---

## Роль дня в петле (не расширять)

День **кормит ночь фактами**, ночь **даёт дню вопросы**. Каждый день:
1. Конверт директивы (WS5.2) — получить в конторе компании (а не найти на столе).
2. **Один** предмет улики на день → факт в `KnowledgeStateStore`, который меняет чтение одной передачи ночи
   (например, имя пациента из лавки → в ночи 4 это имя узнаётся на проводе).
3. Одно последствие прошлой ночи видно в городе (маршрут 17: поезд на путях / его нет; цитация: клерк холоден).

Никаких квестов, инвентаря, диалоговых деревьев. Разговоры — записки, вывески, объявления, реплики одной
строкой (GDD §36.3 — голос Элиаса: заметки на полях его рукой).

## Контракты

- Все переходы день↔ночь — через `NightSequence` (WS5.1) и сохранение; поля дня — `DayData.tres`
  (`evidence_item_id`, `envelope_directive`, `consequence_checks: Array[StringName]`).
- Улика = `Interactable` + документ во вьюере (`DocumentRouter`); чтение = факт знания. Физически меняет мир
  только игрок или объяснимая сила (правило Listener распространяется на город).
- Сцены: `scenes/town/street.tscn` + по сцене на интерьер. PSX-пайплайн тот же (360 строк, 5 бит, Bayer).
- Производительность: весь город ≤ 2 света с тенями одновременно; интерьеры — отдельные сцены, не стримминг.

## Порядок (каждый шаг — отдельный план задач при старте)

1. **Серый бокс улицы** (депо ↔ контора ↔ пансион), ходьба, дверь в офис телеграфа. Проверка: 90 с от
   пансиона до депо — не больше.
2. **Контора компании** (интерьер 1) + конверт директивы. Проверка: день 2 → директива ночи 2 из конторы.
3. **Предмет улики** + факт → изменение одной передачи ночи. Тест: без факта передача читается A, с фактом — B
   (разница только в `elias_perception`/знании, не в `true_message`).
4. **Последствие прошлой ночи** в мире (поезд/клерк). Тест на каждый факт-потребитель.
5. Лавка, пансион, дом доктора — по одному, каждый доведён до §35 до начала следующего.
6. Звук города: одна петля улицы + по одной на интерьер; колокол депо по часам станции.

## Гейты
- Плейтест: день ≤ 6 минут, игроки называют, зачем пришли в каждое место.
- Никакой локации «на потом»: не доведено до §35 — не входит в сборку.
