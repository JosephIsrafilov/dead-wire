## Как работать
Для каждой задачи фазы, по порядку:

3. Минимальное изменение, которое даёт результат. Сначала настрой существующие узлы,
   материалы и свет; новые системы — только если без них никак, и тогда сначала спроси.
4. Кадры «ПОСЛЕ» с тех же камер, с теми же настройками. Посмотри на них сам. Headless-прогон

## Не нарушать никогда
- Слои сигнала TRUE → PERCEPTION → TRANSCRIPT не схлопываются.
- TapeRegister знает только MARK/GAP и никогда не получает текст. Любая визуализация ленты
  строится из его записи.
- Writer rig: advance_presentation тратит время тика один раз; не больше одного глифа за тик;
  чернила только на glyph_contact.
- Критическая морзе всегда разборчива; никаких стингеров поверх критической копии.
- Listener не трогает предметы. Фигура появляется и исчезает только между наблюдениями,
  во время передачи не меняется.
- WorldState и KnowledgeState — разные хранилища.
- Контент (сценарии, мысли, ритм ночи) — в .tres, не в коде.
- Незакоммиченная работа владельца в дереве неприкосновенна: никаких revert / stash /
  reset / checkout -- / git add -A / commit -a. Не пушить, историю не переписывать.

## Арт-направление (GDD §35; кратко)
Один тёплый свет (настольная лампа) и один холодный (луна через окно), ambient почти ноль.
Темноту лечить лунным пятном, контровым светом и значением материала, а не новой лампой.
Тепло — локально, остальное холодное и приглушённое. Плотность текселей одинаковая; глубина
снаружи — простая геометрия и туман, а не пиксельные щиты. Бумага не ярче лампы, текст на ней
всегда читаем. Без статус-строк, без модальных панелей, без современного гротеска. Без CRT,
VHS и хроматической аберрации. Тест: зритель 30-секундного ролика решит, что игра стоила
дороже, чем стоила?

## Заметки для владельца

- **Сколько фаз за раз.** По умолчанию одна. Если доверяешь агенту на механической фазе
  (например 1 или 6), можешь написать «фазы 1 и 2 подряд, остановись после каждой с кадрами» —
  он всё равно покажет промежуточный результат.
- **Если агент ушёл в невидимую работу** — отправь ему одну строку: «Правило AGENT_RULES §1:
  что изменилось для игрока?»
- **Ответы на [решение] можно дать заранее.** Допиши их в первое сообщение агенту, например:
  «Решения: 3.10 да, 4.11 да, 4.14 нет, 5.7 да, 7.12 заменить, 8.11 да, 3.12 нет, 1.13 два
  режима». Агент внесёт их в таблицу решений и не будет останавливаться на этих пунктах.
- **Если хочешь быстрее к плейтесту** — напиши «только ★». Агент пропустит ○ и ◇ и перечислит
  их в «Позже».
