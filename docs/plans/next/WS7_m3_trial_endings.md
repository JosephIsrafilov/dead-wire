**Уровень плана:** милестоун; первая задача (функция концовок) расписана полностью — её можно и нужно

**Источники:** `docs/design/DEAD_WIRE_HORROR_LAYER_DESIGN.md` §7 (ход суда), GDD §17 (цепочка улик), §18 (финалы).

### Task 7.1 — Одна функция концовок (риск STATE §4)

**Files:** Create `scripts/story/ending_table.gd`:
```gdscript
class_name EndingTable
extends RefCounted

enum Ending { SEND_NOTHING, LIMITED, MINIMAL_HONEST, FULL }

static func ending(world: WorldStateStore, knowledge: KnowledgeStateStore, trial_answers: Dictionary) -> Ending:
	# Each row reads facts only; the table is the whole ending logic.
	...
```
**Строки таблицы (черновик для владельца, заполнить в `docs/design/ENDINGS.md` одновременно с кодом):**

| Условие | Финал |
|---|---|
| в суде ≥ N молчаний и не вскрыта ни одна улика | SEND_NOTHING |
| вскрыта ≥1 улика, но на WATER→WATCHER ответ «ОТРИЦАТЬ» | LIMITED |
| подтверждено по ленте + ≥2 улики §17 | MINIMAL_HONEST |
| подтверждено + ≥4 улики §17 + самопризнание Элиаса | FULL |

Цитации ≥3 не меняют финал напрямую — открывают ветку «давление» (вопрос в суде), GDD §18 «не мораль-метр».
**RED:** `tests/story/ending_table_test.gd` — **один тест на строку** + тест «сторы не мутируются функцией».
**Правило:** ни один другой скрипт не решает, какой финал; сцены финалов читают только `EndingTable.ending(...)`.
**Commit:** `feat: one table decides the ending`

### Task 7.2 — Сценарий суда в данных

`scripts/story/trial_data.gd` + `data/trial/sunday.tres`: очередь вопросов диспетчера (`question_text`,
`requires_fact`, `answers_allowed`), зачитка ленты (берётся из реального `TapeRegisterController` записи ночей —
сохранять MARK/GAP ночей 1–6 в сейв, это не текст, инвариант не нарушен).
Ответы — ключом (5.7): ПОДТВЕРДИТЬ = отбить слово с ленты; ОТРИЦАТЬ = отбить своё; МОЛЧАНИЕ = пауза этикета
истекла; ВСКРЫТЬ = отбить номер улики.

### Task 7.3 — Пауза этикета

15–20 с на ответ (поле в `trial_data`); истекла = МОЛЧАНИЕ. Никакого HUD-таймера — диспетчер повторяет вопрос
один раз (`RPT?`) на половине времени.
**RED:** trial test — нет нажатий 20 с → ответ `SILENCE`, записан один раз.

### Task 7.4 — Компания перебивает, после 3-го возражения — урезана

`WireService` приоритет `SERVICE` врезается BK-сигналом в неудобные вопросы (`requires_fact` из списка компании).
Счётчик возражений; после 3-го аудитор урезает линию компании → дальше её сообщений на проводе нет.
**RED:** 4-е возражение не звучит; лента не содержит его MARK.

### Task 7.5 — Финальный кадр

Лента останавливается; последнее на ней — передача игрока. Короб с шестью днями бумаги. Никакой карточки
«THE END» поверх — только документ во вьюере (`DocumentRouter`).

## Гейты
- Каждая строка таблицы концовок достижима в тестовом прогоне (скрипт `tools/ending_matrix.gd` headless:
  синтетические сторы → все 4 финала).
- Плейтест суда: игроки понимают, что отвечают **ключом**, без текста-подсказки (≥4/5).
