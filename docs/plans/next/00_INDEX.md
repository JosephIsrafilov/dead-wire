# DEAD WIRE — планы реализации (с 2026-09-27)

Для любой модели, которая подхватывает проект. Сначала прочитать `docs/HANDOVER.md` (состояние, ловушки,
соглашения), затем `docs/plans/2026-09-27_STATE_OF_THE_GAME.md` (диагноз). Номера проблем `#N` ниже ссылаются
на §3 диагноза.

## Как исполнять любую задачу из этих планов

1. `bash tools/run_all_tests.sh` — записать базовую линию (на момент написания: **38 suites / 1915 assertions**).
2. Прочитать секцию «Контракты существующего кода» плана и указанные файлы целиком.
3. **Тест сначала** (RED): добавить проверку в указанный suite или новый `tests/**/<name>_test.gd`
   (шаблон — `HANDOVER.md` §7). Запустить фокусно, убедиться, что падает по нужной причине.
4. Минимальная реализация (GREEN). Никаких абстракций «на будущее».
5. Фокусный suite → полная регрессия → `.venv-tools/bin/gdlint scripts/`. Число suites и assertions не падает.
6. Если задача визуальная: оконный захват (`HANDOVER.md` §4) + просмотр кадра; headless ≠ визуальная приёмка.
7. Если менялся маршрут игрока/интерактивы: `godot --path . --script tools/production_evidence_capture.gd`
   (57 PASS) и `godot --path . --script tools/first_night_playthrough.gd -- --capture` (58 PASS).
8. Обновить статус задачи в этом плане (`- [x]`) и, если меняются факты, GDD/HANDOVER — в том же коммите.
9. Коммит от имени владельца (`HANDOVER.md` §8), **только явные пути** (в индексе могут лежать чужие файлы).

Критический путь: **WS1 → WS2 (плейтест!) → WS4 → WS5**. Не строить WS5+ до вердикта плейтеста M1
(GDD §28: «не спасать слабую петлю нарративом»).

## Защищённые инварианты (нарушение = сломанная честность игры)

Полный список — `AGENTS.md`. Кратко: слои сигнала TRUE → PERCEPTION → TRANSCRIPT не схлопываются; регистр
пишет только MARK/GAP и не знает текста; один presentation tick = максимум один глиф, чернила только на
`glyph_contact`; критическая морзе всегда читаема, шум ест только некритичное, никаких стингеров поверх
критической копии; Listener не трогает предметы, фигура только в зазоре наблюдений; WorldState ≠ KnowledgeState;
контент — в `.tres`.
