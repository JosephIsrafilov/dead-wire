# DEAD WIRE — instrument-first: утверждённый ограниченный проход

## Понимание и границы

Владелец подтвердил существующую M1 и выбрал instrument-first среди трёх вариантов.
Сохранить 1894, disciplined PSX, три передачи и раздельные TRUE / PERCEPTION / TRANSCRIPT.
Не строить город, новые ночи, monster chase, новую кисть или звуковой микс.
Незакоммиченный прежний проход сохранён отдельным checkpoint f82939d и отправлен в
origin/codex/hand-rebuild-handoff. Локальный Python env/bytecode/credentials исключены.

Предположения: одиночная PC-игра, целевой60fps (это цель, не измеренный результат),
локальная обработка, без платной генерации/внешней отправки проекта; авторские assets,
редактируемый Blender-source плюс воспроизводимый builder. Новые материалы не затрагивают
существующую бумагу/шрифты/руку. Разгадку/канон/тайминги не менять в арт-pass.

## Решения

| Решение | Альтернативы | Причина |
|---|---|---|
| Instrument-first | Hand-first / atmosphere-first | Самые близкие к игроку объекты петли; изолированная интеграция |
| Авторские Blender-меши, glTF | Ассет-пак / CSG-detail | Одна палитра, короткий pipeline, независимость от поставщика |
| Static и moving assemblies отдельно | Монолитный GLB / новая анимационная система | Сохранить Lever, ArmatureBar, Spool, StylusPivot и runtime |
| Текущие colliders/pivots оставить | Перестройка стола и взаимодействий | Не ломать маршрут/attention/контракты |
| Gameplay-изменения специфицировать отдельно | Тихий rewrite в арт-pass | Нейтральная поправка требует ввода игрока и новых outcome-контрактов |

## Дизайн арт-pass

Key: скруглённая тёмная деревянная подошва, листовая латунная площадка, опоры оси,
контактные винты, клеммы, тёмная хватовая кнопка; lever отдельным mesh на старом pivot.
Sounder: две катушки с видимым направлением обмотки, железное основание/латунная стойка,
слотированные крепежи и отдельная движущаяся armature. Register: деревянный корпус с
сдержанными швами, крепление катушки/направляющие/боковой завод, отдельные spool/stylus;
существующая объективная лента и paper-strip сохранены. Никаких фальшивых надписей
производителя и необоснованной исторической точности: это периодически правдоподобные
стилизованные приборы, не музейные реплики.

Материал: единый authored atlas, nearest-filter, умеренные тёмные латунь/железо/wood/
coil/ebonite. Износ по материалу, а не белый random noise везде. Geometry budget ограничен,
нет displacement/subdivision, collider остаётся простым. Сначала источник и экспорт,
затем scene integration. Новые assets идут под assets/models/instruments_v1.

## Проверка и риски

- RED-тест: production scene содержит новые imported mesh assemblies; сохранены размеры,
  collider/pivot/движение, nearest texture и bounded triangle count.
- GREEN: import, focused hardware/material suite, полный regression, production boot.
- Реальные windowed720p before/after и короткий mark/key/spool motion capture.
- Не называть render/автоматический маршрут человеческим playtest, а test green — art approval.
- До прохода:44 suites passed/1 failed (intro_music normal fade),2016 assertions по passed suites;
  изоляция intro_music сноваFAIL. Текущие shutdown/TextureRID leaks не устранены.
- Сервис image review не принимает image input. Captures можно передать владельцу;
  художественная приёмка остаётся открытой, если visual tool не заработает.
- Никакого commit/push нового pass без отдельного разрешения: запрос владельца был
  сохранить то, что существовало до него.

## Gameplay brainstorm — следующие эксперименты, не уже реализованные механики

1. **Проверить, потом подписать.** Убрать WATER из pre-decision меню: FILE AS COPIED /
   AMEND COPY. Поправка — отдельный короткий ввод после явного действия; неверный ответ
   остаётся реальным выбором, не silently corrected. Объективная лента не выдаёт готовый перевод.
2. **Обычная работа обучает сомнению.** Первый telegram безопасно учит tape+card сверке;
   второй заставляет опираться на одно правило ledger; третий ломает доверие к руке.
   Не добавлять tutorial HUD, который объявляет mismatch. В существующем canon сценарии
   проверять как диагностический prototype, не придумывать новую катастрофу.
3. **Материальный след решения.** После авторитетного принятия — короткий путь stamp;
   след/звук ровно на контакте. Не менять outcome ради анимации, не повторять уже имеющееся.
4. **Тот же документ в руке.** Краткий подъём текущего листа, затем доступный viewer с
   тем же ink/layout. No duplicate truth; Esc/E spam не создаёт второй документ.
5. **Угроза требует отвернуться к работе.** После тревожного окна дать существующей работе
   вернуть внимание к sounder; аномалия меняется только между наблюдениями. Новые события/
   перестановка сценариев требуют отдельного owner/canon approval.
6. **Рабочая тишина, не chores.** Измерить реальные паузы и действия новичков, прежде чем
   менять20/38/50с. Регистр/фитиль — осмысленные удобства, не обязательная бесконечная рутина.

Первый gameplay patch: нейтральные подписи + корректный amendment input/outcome + tests,
не косметическая замена текста с оставленным автоматическим file_water. Второй: предметная
непрерывность. Письмо по штрихам и foley — отдельный pass из TACTILE_M1, не hidden scope.

Человеческая приёмка:5 новых игроков без подсказки, с согласия на локальную запись.
Спросить, когда обнаружили расхождение и чем его доказали, не произнося WATER заранее.
