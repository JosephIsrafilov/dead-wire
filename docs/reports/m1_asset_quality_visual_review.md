Место: scenes/office/m1_office.tscn, NorthWall_MidLeft / NorthWall_Right, около строк 229–238.

- Между ними остаётся примерно 1.72 m незакрытой стены по всей высоте.

Прохождение всего игрока через стену не прогонялось; визуальный разрыв и отсутствие collision подтверждены отдельно.

Исправить:
1. Пересобрать покрытие северной стены под единственный новый оконный проём.
2. Согласованно обновить wainscoting, trim, верх/низ проёма, exterior и collision.
3. Проверить серию rays/capsule positions по всей стене, а не одну контрольную точку рядом с окном.
4. Показать кадр входа и пройти вдоль стены без выхода наружу.

Не закрывать дыру случайным шкафом или декоративным plane без collision.

## 3. Q2 [P1] Рука визуально разъединена

Место: scripts/telegraph/ui/writer_rig.gd, set_writing_progress, около строк 187–193; scenes/telegraph/transcript_paper.tscn.

03_writing_2.png показывает отдельные части руки/манжеты над листом; цель «рука принадлежит телу» не достигнута.

Причина в коде: две жёсткие дочерние детали независимо смещаются через hand.global_position и wrist.global_position, а forearm остаётся неподвижным. Это не сгиб сустава: относительные расстояния деталей меняются. Contact nib может пройти тест, пока кисть отсоединена от рукава.

Исправить:
- Сохранить непрерывность кисть→запястье→предплечье.
- Использовать вращение вокруг согласованных pivot или небольшой деформирующий rig; при движении жёстких деталей ограничивать translation так, чтобы стыки не расходились.
- Выставить rest позу сразу около рабочей области, чтобы первый glyph не требовал большого перемещения кисти.
- Не возвращать длинную палку ради сохранения topology.
- Проверять несколько glyphs/строк, enter/suspend/resume/withdraw, крайние yaw/pitch.
- Добавить joint continuity / bounded relative offset checks вместе с nib-contact tests.
- Снять видео с рабочей камеры. Числовая длина 0.28 m сама по себе ничего не доказывает.

Исправить:

## 6. Q5 [P2] «Seated gameplay evidence» снято стоя и с auto-aim

Место: tools/window_evidence_capture.gd, около строк 64–68 и helpers _stand_and_walk / _turn_to.

- Перед w2_seat_turn вызывается _stand_and_walk, который встаёт со стула и напрямую присваивает player.global_position.

Это полезный logic/visibility fixture, но он не доказывает обещанный естественный seated/commit путь.

Исправить:

2. Для seated shot реально вызвать/выполнить посадку, дождаться is_settled, проверить is_seated перед capture.
3. Поворот — mouse/look input через production handler с действующим yaw clamp.
4. Один отдельный проход оставляет director/session/scheduler/paper processing включённым и проходит маршрут обычным movement/E.
5. Флаги появления логировать, но не выдавать их за визуальную узнаваемость.
