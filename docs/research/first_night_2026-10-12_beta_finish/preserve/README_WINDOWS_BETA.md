# DEAD WIRE — Windows Beta

## Start here

1. Extract the complete ZIP to a folder you can write to.
2. Double-click `dead-wire-windows-beta-x86_64.exe`. No Godot editor is required.
3. If Windows SmartScreen warns about an unknown publisher, this unsigned beta has no verified publisher identity. Only continue if you trust the person who supplied it.

This is a work-in-progress first-person night shift in a small telegraph office. Your task is to carry out the work, use the available records and tools, and see the shift through. The game does not require a particular interpretation or answer.

## Controls

- **W / A / S / D** — move
- **Mouse** — look
- **E** — interact with the indicated object
- **Esc** — close a document or open/pause the menu (context-dependent)
- **1 / 2** — select a displayed option when the interface offers numbered choices

Contextual thoughts offer brief, situation-specific procedural reminders; they are not required reading. Press **F1** to repeat the current reminder when available. You can turn contextual thoughts on or off in the options.

The pointer may be captured during play. Follow the on-screen prompt for returning to menus or releasing control. Options include separate **Telegraph** and **Foley** volume controls plus display/readability settings.

## Sound status

Sound is functional but provisional. Telegraph signals must remain audible; some mechanical and room sounds are temporary placeholders. Please report missing, distorted, unexpectedly loud, or obstructive audio using the separate beta report form. The sound-engineer brief contains story information: save it until after your first playthrough.

## Privacy and feedback

The game has no automatic feedback upload. If you choose to send a report, do not include your name, device identifiers, account details, or raw text you entered in the game. Sending a report is optional.

## Beta limitations

This is a beta, not a release. It may contain unfinished presentation or stability issues. A human beta tester, including a sound engineer, is being asked to assess bugs and playability; this README does not claim five-player validation. Please use the included report form for reproducible issues. Participation and reporting are optional.
